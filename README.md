# Genomac Certificate Generator (Frontend)

This is the frontend application for the **Genomac Certificate Generator** project.

## Overview

The Genomac Certificate Generator frontend provides a user interface for generating and managing certificates. It interacts with the backend API to create, view, and download certificates.

## Features

- User-friendly certificate generation form
- Real-time certificate preview
- Download certificates as PDF
- Integration with backend API

## Tech Stack

- Framework: [React](https://react.dev/) (or specify your framework)
- Styling: (e.g., Tailwind CSS, Material UI)
- State Management: (e.g., Redux, Context API)
- HTTP Client: (e.g., Axios, Fetch API)

## Getting Started

1. **Clone the repository:**
  ```bash
  git clone <repo-url>
  cd genomac-certificate-generator-frontend
  ```

2. **Install dependencies:**
  ```bash
  npm install
  ```

3. **Configure environment variables:**
  - Create a `.env` file and set the backend API URL.

4. **Run the development server:**
  ```bash
  npm start
  ```

5. **Build for production:**
  ```bash
  npm run build
  ```
